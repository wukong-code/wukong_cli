# SPDX Lite Dependency Inventory

This file is generated from the committed lockfiles and package manifests by the
release pipeline. It is intentionally a small, reviewable inventory of the
first-party package graph; release-specific SBOM assets contain the complete
resolved dependency graph and artifact hashes.

## Generation contract

A release must publish:

- an SPDX or CycloneDX JSON SBOM for the npm package and native bundle;
- a dependency license report with package name, version, license expression,
  source URL, and integrity/hash where available;
- the source commit and artifact SHA-256 values used to generate both files.

The release must fail if a dependency license is unknown or if the generated
reports do not match the lockfile and package contents. Do not edit this file by
hand to represent a release.
