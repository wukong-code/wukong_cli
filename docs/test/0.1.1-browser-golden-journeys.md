# 0.1.1 浏览器 Golden Journeys

> 范围：验证未发布 `0.1.1` 工作树的官网产品边界和 local Web 基本链路。
> 这不是 production、真实 OAuth callback、Cloudflare D1 或公开 release 验收。
> 每次修改官网核心文案、Device Login 跳转、local Web 鉴权、Workspace 或消息流后重跑。

## 1. 官网：Home → Download → Pricing → Device Login

从 `wukong_web` 仓库启动官网：

```sh
npm run dev -- --hostname 127.0.0.1 --port 3015
```

浏览器逐页检查：

1. 打开 `http://127.0.0.1:3015/`。
   - 显示当前公开版本 `v0.1.0`，不能把未发布 `0.1.1` 写成 current。
   - 明确产品为 Free、BYOK、无需 Wukong 账号。
   - Loop 是 bounded；PASS 之外仍保留 blocker/next action 和非 PASS 终态。
2. 打开 `/download`。
   - 六个平台资产继续指向 `v0.1.0`，并显示 SHA-256 校验。
   - Quick Start 包含 project、provider、interactive agent 和 `/loop`。
3. 打开 `/pricing`。
   - 只有 `$0` Free；没有 Checkout、Pro/Team 或 Wukong 托管推理额度。
   - 文案明确模型费用由用户选择的 provider 收取。
4. 用本地 Device Authorization API 创建一次 code，再打开返回的
   `verification_uri_complete`：

   ```sh
   curl --noproxy '*' -sS -X POST \
     http://127.0.0.1:3015/api/oauth/device_authorization \
     -H 'content-type: application/x-www-form-urlencoded' \
     --data 'client_id=17e5f671-d194-4dfb-9706-5516cb48c098'
   ```

   - 未登录用户跳到 `/auth/signin`。
   - `callbackUrl` 精确保留 `/auth/device?code=...`，页面明确这是可选账号的
     Device Login，不把登录变成 local BYOK CLI 的前置条件。
   - 本地检查到这里结束；真实 Google/GitHub 登录、approve、token exchange、
     revoke 属于 production release gate，不能用本地跳转代替。

每一页运行 `console error`，结果必须为 0。截图保存到：

## 2. Local Web：token → Workspace → Session → streamed reply

从 `wukong_cli` monorepo 根目录启动两个服务：

```sh
# Terminal 1
WUKONG_STUB_PORT=58628 \
WUKONG_STUB_WEB_URL=http://127.0.0.1:5175/#token=stub-local \
  pnpm -C apps/wukong-web run dev:stub

# Terminal 2
WUKONG_SERVER_URL=http://127.0.0.1:58628 \
  pnpm -C apps/wukong-web run dev --host 127.0.0.1 --port 5175
```

1. 打开 `http://127.0.0.1:5175/#token=stub-local`。
2. 确认地址栏立即变成不含 token 的 `http://127.0.0.1:5175/`，且 Server Auth
   先于 onboarding 完成。
3. 完成或跳过 onboarding；确认 stub Workspace 可见。
4. 输入一条消息并发送。
5. 确认创建真实 Workspace/Session 请求，URL 进入 `/sessions/<id>`，用户消息与
   `Stub response: ...` 回复均可见。
6. 检查网络请求：health、meta、auth、config、workspaces、sessions、snapshot、
   status、skills 和 prompts 均为 HTTP 200。
7. 运行 `console error`，必须为 0；localStorage 不得保存 bearer token。
