# Wukong Code 0.0.17 — Command Surface Reliability

> Released: 2026-07-22
>
> Distribution: free/BYOK native binaries for macOS, Linux, and Windows.

0.0.17 makes the existing CLI and TUI command surface easier to discover and
harder to misuse. It also removes remote Guest/monthly quota gates from local
BYOK Loops and strengthens Loop cancellation, recovery, and reviewer bounds.

## Command surface

- Remove the misleading global and Loop `--role` flags and the TUI `/role`,
  `/report`, and `/yes` aliases.
- Use `wukong roles list|show|init` to manage experimental Role Profiles and
  `/transform list|status|off|<role>` to change the current TUI session.
- Keep `/transform` visible while Role Profiles are disabled and provide local
  `/experiments` guidance without sending the command to the model.
- Keep unknown, disabled, unavailable, and invalid slash commands local. Removed
  commands now show explicit migration guidance instead of misleading fuzzy
  suggestions.
- Make `/resume` canonical with `/sessions` as a compatibility alias. Keep
  `/login` account-only and `/provider` responsible for model API keys.
- Align `/export` with ZIP export and use `/export-md` for Markdown.

## Loop reliability

- Remove Guest trials, monthly Loop allowances, remote start/complete
  accounting, and quota-service warnings from local BYOK execution.
- Preserve the default 10-iteration safety limit and explicit
  `--max-iterations`, reviewer, cancellation, and `/loop stop` boundaries.
- Keep headless execution alive across continuation turns and make `--every` a
  cancellable Goal-owned delay instead of detached cron work.
- Bound the fresh read-only reviewer to 8 steps or 2 minutes, reconcile blocker
  replacements safely, and cancel deterministic checks promptly.
- Migrate quota-era local recovery records to content-free lifecycle v2 without
  adding a Web/D1 metrics backend.

## Upgrade notes

| Removed entry | Use instead |
|---|---|
| `wukong --role <role>` | TUI `/transform <role>` |
| `wukong loop --role <role>` | Configure writer/reviewer models, then use `/transform` in TUI |
| `/role list` or `/role off` | `/transform list` or `/transform off` |
| `/report` | Loop/Gate result, `/proof`, `/export-md`, or `/export` |
| TUI `/yes` | `/permission`, `/auto`, or explicit `/yolo` |
| Markdown through `/export` | `/export-md` |

The release remains free and BYOK. It does not add payment, Checkout,
entitlement, PR publishing, Team features, hosted execution, managed model
credits, or a Web/D1 product-metrics backend.
