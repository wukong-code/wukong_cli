# Wukong Code 0.0.21

0.0.21 is a focused Loop evidence-integrity patch.

## What's changed

- Built-in risk findings now use a stable identity derived from the complete
  occurrence: risk kind, severity, message, file, line, and evidence.
- Distinct occurrences of the same risk kind now reach the reviewer broker
  separately instead of later findings being rejected as duplicate input.
- Identical occurrences retain the same deterministic identity, so exact
  duplicate input can still be deduplicated.
- Regression coverage verifies that findings with the same risk kind at
  different files and lines both reach the bounded reviewer input.

## User impact

`/loop` reviewers now receive the complete set of distinct built-in risk
findings for the current Gate attempt. No new command or configuration is
required, and deterministic failures still cannot be overridden by a reviewer.

## Scope

The release must provide the same feature surface on macOS, Linux, and Windows.
It does not include isolated worktrees, Candidate Gate, Safe Promote, target
Final Gate, Windows FFI, or platform-specific execution behavior.

Wukong Code remains free, local-first, and BYOK. This release adds no hosted
execution, managed model credits, payment, quota, entitlement, source upload,
or telemetry backend.
