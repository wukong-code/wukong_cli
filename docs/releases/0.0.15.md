# 0.0.15 Release Notes

> Status: release candidate. The current public download remains 0.0.14 until
> the full release gate, six native assets, manifest, and announcement are
> verified.

0.0.15 focuses on Loop reliability and first success. It does not add payment,
GitHub PR automation, Hosted Report, managed model credits, or new Agent
sources.

## Loop lifecycle

- Each signed-in Loop keeps a local `0600` record mapping its quota request to
  the Wukong Goal, session, and workspace.
- PASS, NEEDS_WORK, ERROR, cancelled, and abandoned are separate lifecycle and
  code-outcome concepts. Cancellation never fabricates a Gate conclusion.
- Completion failures enter a local outbox with bounded backoff and retry on
  startup, resume, `today`, `doctor`, and the next Loop.
- On restart the TUI offers Resume, End as cancelled, or View details. Resume
  re-reads the workspace, Git state, project checks, and review policy.

## Shorter first-success path

- Preflight validates the objective, model, workspace, active Goal, and check
  discovery before quota is reserved.
- The initial TUI highlights only Continue a task, Start a Loop, and Configure
  model.
- Final Loop output defaults to Gate, Iterations, primary Blocker, and Next.
- A source change with no checks returns NEEDS_WORK with `.wukong/checks.json`
  guidance. An unavailable tool is not reported as a failed test.

## Dashboard and measurement

- Dashboard shows real active, stale, completed, cancelled, and abandoned Loop
  states without restoring Reports or Hosted Report.
- Protected metrics separate registered, activated, completed, repeated users,
  terminal reporting rate, lifecycle states, and code outcomes.
- Installer and CLI product telemetry is limited to install/first-run/Resume/
  Loop lifecycle events. It excludes source, prompt, transcript, repository,
  path, model, terminal, locale, and OS-version data.
- Set `WUKONG_TELEMETRY=0` to disable anonymous telemetry without changing the
  local Loop.

## Verification coverage

The release gate covers restart, offline completion, cancellation, duplicate
completion, old payload compatibility, real Node/Python/Rust/Go projects, no
checks, missing tools, and Cross-Agent Resume → editable Loop handoff.
