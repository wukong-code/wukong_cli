# Wukong Code 0.2.0

`0.2.0` is the Standalone Gate & Proof Foundation release, released on 2026-11-24.
It extracts Wukong's deterministic check runner, independent fresh-context reviewer,
and sanitized PR delivery proof card into standalone commands that work on top of
changes written by any AI coding agent or editor.

## Highlights

- **`wukong init`**: Automatically detects Node (`pnpm` / `npm` / `yarn`), Python,
  Rust, Go, and monorepo workspace toolchains, scaffolds `.wukong/checks.json` and
  `.wukong/review-policy.md`, and guides interactive provider setup and verification.
- **`wukong provider test [providerId]`**: Explicitly runs a minimal connectivity and
  credential check classifying `ok`, `auth-failed`, `not-found`, `network`,
  `timeout`, and `offline` outcomes without logging API keys, query secrets, or raw
  response bodies.
- **`wukong check`**: Runs deterministic project checks and built-in risk scans
  offline without invoking a model, explicitly reporting `reviewer: not_run` so
  local check passes never masquerade as a complete Gate `PASS`.
- **`wukong gate`**: Executes `checks + risk scan + fresh-context reviewer` directly
  against the current working tree or `git diff` outside `/loop`, returning a
  fail-closed `PASS`, `NEEDS_WORK`, or `ERROR` verdict.
- **`wukong summary` / `wukong gate --summary`**: Renders and optionally saves a
  sanitized PR-ready Markdown Delivery Proof Card that discloses unverified areas and
  excludes source code, diffs, transcripts, secrets, and home paths by default.
- **Command surface convergence & single-confirm headless run-plan**:
  `wukong --help` highlights the 8 core commands (`init`, `check`, `gate`,
  `summary`, `loop`, `provider`, `doctor`, `upgrade`) while preserving full access
  via `wukong help --all` and `0.1.x` compatibility aliases. Headless `wukong loop`
  adds `--dry-run --plan-out <file>` and `--plan <file> --approve-plan <digest>` as
  a secret-free, single-confirm workflow bound to workspace identity and a 10-minute
  validity window.
- **Unified onboarding**: Aligns `install.sh`, postinstall quickstarts, and
  `wukong doctor` around `wukong init` → `wukong check` → `wukong gate`.

## Compatibility & Licensing

- Free, local-first, and bring-your-own-key (BYOK) under the MIT License; requires no
  Wukong account, cloud backend, or hosted inference to run local verification gates.
- Existing `0.1.x` subcommands (`verify`, `scan`, `proof`, `judge`, `guard`),
  configuration files, and legacy `--until` / headless flags remain compatible.

## Install or upgrade

```bash
curl -fsSL https://wukong.today/install.sh | sh
wukong upgrade
```
