# Wukong Code 0.1.2

`0.1.2` 是开源发布版（Open-Source Edition，2026-10-24 发布）。它不新增
顶层命令，不改变 Loop/Gate 判定语义，也不包含 Cost Visibility 或新的付费
功能；命令与行为面与 `0.1.1` 一致。

## 开源与许可

- 源码仓库 `wukong-code/wukong_cli` 自本版起公开，整体以 MIT 许可发布：
  根 `LICENSE` 与全部 package 的 license 字段统一为 MIT，README 与
  CONTRIBUTING 的许可声明同步更新。
- npm 包 `@wukong.today/code` 自本版起从公开仓库发布并携带 provenance。
- 官网与业务后端（`wukong_web`）保持私有；二进制分发与文档仓库仍为
  `wukong-code/wukong-code`，`latest` 指针、六平台资产与 sha256 清单的
  验收链路不变。

## 仓库迁移与链接修正

- 三个仓库已从 `mutnpc` 组织迁入 `wukong-code` 组织；二进制内嵌的
  feedback、changelog、installer 与 announcement 链接全部指向新组织与
  `wukong.today`。
- 历史 CHANGELOG、源码注释与测试 fixture 中的旧组织地址统一修正；banner
  白名单继续拒绝指向迁移前组织或未批准域名的公告链接。
- `wukong upgrade` 沿用基于上一个实际 stable 的升级基线校验，从 `0.1.1`
  升级到 `0.1.2` 无需额外操作。
