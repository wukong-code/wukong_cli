# Wukong Code 0.1.2

`0.1.2` is the open-source edition, released on 2026-10-24. It adds no top-level
commands, does not change Loop/Gate semantics, and does not introduce Cost
Visibility or new paid features. The command and behavior surface remains
consistent with `0.1.1`.

## Open Source and Licensing

- The source repository, `wukong-code/wukong_cli`, is public under the MIT
  License starting with this release. The root `LICENSE` and all package license
  fields are aligned with MIT, and the README and CONTRIBUTING license
  statements have been updated.
- The `@wukong.today/code` npm package is published from the public repository
  with provenance starting with this release.
- The website and operations backend (`wukong_web`) remain private. Binary
  distribution and public release documentation remain in
  `wukong-code/wukong-code`; the `latest` pointer, six-platform assets, and
  SHA-256 verification flow are unchanged.

## Repository Migration and Link Updates

- All three repositories moved from the `mutnpc` organization to the
  `wukong-code` organization. Embedded feedback, changelog, installer, and
  announcement links now point to the new organization and `wukong.today`.
- Historical changelogs, source comments, and test fixtures were updated to
  remove the old organization URLs. The banner allowlist continues to reject
  links to the former organization and unapproved domains.
- `wukong upgrade` continues to validate its upgrade baseline against the
  previous actual stable release. Upgrading from `0.1.1` to `0.1.2` requires no
  additional steps.

## Install or upgrade

```bash
curl -fsSL https://wukong.today/install.sh | sh
wukong upgrade
```
