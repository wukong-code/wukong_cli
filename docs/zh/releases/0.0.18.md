# Wukong Code 0.0.18

0.0.18 makes the normal path smaller: resume unfinished work, give Loop a goal,
and let the Gate decide whether the change is ready.

## What's changed

- The default TUI command list now shows only the core workflow. Run
  `/help advanced` for diagnostics and configuration tools. Existing advanced
  and compatibility implementations remain callable; `/goal`, `/auto`, and
  `/yolo` are hidden rather than deleted.
- `/resume` now discovers local Kimi Code and Grok sessions in addition to
  Wukong, Codex, Claude Code, and Cursor. Imports are read-only, bounded, and
  reject metadata paths that escape each source's local session root.
- `/login` opens the Wukong website for Google or GitHub confirmation. A valid
  account may currently receive an empty Wukong model catalog; login still
  succeeds and does not replace an existing BYOK default model.
- `/feedback` sends only the exact text payload shown for confirmation. It does
  not attach logs, transcripts, prompts, source code, file paths, or local
  evidence, and it does not require login.
- Real model-catalog errors remain visible. Only the expected logged-out state
  is quiet, so an HTTP 404 or server failure cannot masquerade as success.

## Product boundary

Wukong Code remains free and BYOK. 0.0.18 does not add hosted inference,
payments, monthly Loop quotas, Hosted Terminal, cloud sync, or a Web/D1 product
telemetry backend. Wukong-hosted models will appear only after a real backend
and its privacy and end-to-end release gates are ready.

## Install or upgrade

```bash
curl -fsSL https://wukong.today/install.sh | sh
wukong upgrade
```

After release, verify with `wukong --version`; it should print `0.0.18`.
