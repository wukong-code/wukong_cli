# Wukong Code 0.0.14 — Resume into the Loop

> Status: released as `v0.0.14`. The release tag builds native binaries for all six supported targets.

## Install or upgrade

```bash
curl -fsSL https://wukong.today/install.sh | sh
```

Existing 0.0.13 native installations on macOS and Linux can run:

```bash
wukong upgrade
```

## What changed

- `/resume` remains focused on Wukong sessions.
- `/resume codex`, `/resume claude`, and `/resume cursor` discover local sessions from those agents.
- External history is imported as read-only context. Old tools, permissions, and test results are never replayed.
- After selecting a session, choose **Continue in Wukong** or **Start /loop** with an editable objective.
- The TUI now shows one actionable Gate result instead of the ambiguous `Verify ✗ · Proof BLOCKED` combination.
- Python, Rust, and Go projects receive broader real-project check discovery, with missing tools reported as unavailable rather than failed code.
- Hosted Report, report upload, public sharing, and hosted-report quota paths are removed.

## Commercial boundary

0.0.14 remains free and bring-your-own-key. Cross-Agent Resume is an activation path, not a paid feature. Payments, managed reviewer credits, GitHub PR automation, Team policy, and audit remain deferred to 0.1.0 or later.
