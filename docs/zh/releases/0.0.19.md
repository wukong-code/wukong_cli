# Wukong Code 0.0.19

0.0.19 makes Loop completion explicit and harder to weaken silently.

## What's changed

- New TUI Loops open a Finish Line before creating any goal, contract, trust
  grant, or run. Review the Goal, optional Done when, Must not constraints,
  required checks, warnings, and per-run iteration limit.
- Headless Loop supports `--done-when`, repeatable `--constraint` and `--check`,
  discovered-check decisions, exact workspace trust and Gate approval
  confirmations, and a read-only `--dry-run` proposal.
- Required checks freeze their execution/display command, source locator,
  definition, order, risk classification, workspace identity, and policy
  digests. Definition or policy drift fails closed and requires restoring the
  original definition or starting a revised Loop.
- Known inline secrets and recognizable destructive or upload commands are
  rejected before persistence or process spawn. Trusted project checks still
  execute with the current operating-system permissions; this release does not
  claim a complete shell sandbox.
- Gate checks, builtin scan, reviewer result, aggregate, evidence snapshot,
  attempt completion, and terminal result are joined with durable local IDs and
  digests. A PASS terminal must reference one complete PASS attempt.
- Continuing a terminal run creates one idempotent, traceable run under the
  unchanged contract. Changing the finish line creates a new Goal, contract,
  root run, and supersedes lineage.
- Existing V1 contracts and 0.0.18 sessions remain readable. Cross-Agent Resume
  only supplies an editable objective draft; imported text never gains command
  or acceptance authority.

## Product boundary

Wukong Code remains free, local-first, and BYOK. Finish Line contracts, exact
commands, trust grants, and evidence metadata stay on the user's machine and
are not uploaded to Wukong Web. Model input still goes to the exact BYOK
provider selected by the user. This release does not add hosted models,
payments, quota, Hosted Terminal or Report, telemetry storage, cloud sync,
Verification Skill execution, PR Gate, Team features, or `/schedule`.

## Try it

```sh
wukong loop "finish the API migration" --dry-run
wukong loop "finish the API migration" \
  --done-when "compatibility tests pass" \
  --constraint "do not remove legacy response fields"
```

Inside the TUI:

```text
/loop finish the API migration
/loop status
/loop resume
/loop revise preserve the old API while completing the migration
```
