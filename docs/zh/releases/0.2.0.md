# Wukong Code 0.2.0

`0.2.0` 为独立验收与交付证明版本（Standalone Gate & Proof Foundation，2026-11-24 发布）。
本次发布把确定性检查、独立上下文审查与脱敏交付证明卡从 `/loop` 中抽离为独立命令，
可直接在任意 AI coding agent 或本地编辑器生成的改动上运行验收门禁。

## 核心更新

- **`wukong init`**：自动探测 Node（`pnpm` / `npm` / `yarn`）、Python、Rust、Go
  及 monorepo 工具链，生成 `.wukong/checks.json` 与 `.wukong/review-policy.md`，
  并引导完成 provider 配置与连通测试。
- **`wukong provider test [providerId]`**：显式执行最小连通探测，准确区分
  `ok` / `auth-failed` / `not-found` / `network` / `timeout` / `offline` 状态，
  绝不记录或输出密钥、query 凭据与响应原文。
- **`wukong check`**：离线聚合运行项目检查与风险扫描，不调用模型，并显式标注
  `reviewer: not_run`，避免把局部检查通过误判为完整 Gate `PASS`。
- **`wukong gate`**：支持脱离 `/loop` 直接对工作区或 `git diff` 运行
  `checks + risk scan + fresh-context reviewer`，返回明确的 `PASS` /
  `NEEDS_WORK` / `ERROR` 结论。
- **`wukong summary` / `wukong gate --summary`**：从已保存的 Gate / Loop 记录生
  成并可选导出脱敏 PR Markdown 交付证明卡（Delivery Proof Card），如实披露未覆
  盖项，默认不包含源码、diff、对话记录、密钥及绝对 home 路径。
- **命令面三级收敛与 Headless 单一确认 run-plan**：
  `wukong --help` 聚焦 8 个核心命令，完整命令通过 `wukong help --all` 查看，TUI
  core 收敛至 8 个且保留 `/help --all` 与 `0.1.x` 兼容命令；无头 Loop 新增
  `--dry-run --plan-out <file>` 与 `--plan <file> --approve-plan <digest>`，以
  无 secret、绑定 workspace 身份及 10 分钟有效期的单一确认替代多项确认参数。
- **统一新手指引**：统一 `install.sh`、npm postinstall 与 `wukong doctor` 的
  `wukong init` → `wukong check` → `wukong gate` 引导链路。

## 兼容与边界

- 本地 CLI 保持免费、本地优先、BYOK 与 MIT 开源，不依赖 Wukong 账号或云端服务。
- 保留 `0.1.x` 命令别名（`verify`、`scan`、`proof`、`judge`、`guard`）与既有
  Loop 合同、配置和兼容性行为。

## 安装与升级

```bash
curl -fsSL https://wukong.today/install.sh | sh
wukong upgrade
```
