# Wukong Code 0.0.21

0.0.21 improves Loop evidence integrity.

## What's changed

- Built-in risk findings now use a stable identity derived from the complete
  occurrence: risk kind, severity, message, file, line, and evidence.
- Distinct occurrences of the same risk kind now reach the reviewer separately.
- Exact duplicate findings retain the same deterministic identity and can still
  be deduplicated.
- Regression coverage verifies that distinct findings across files and lines
  are preserved.
- The same behavior ships across macOS, Linux, and Windows.

## User impact

`/loop` reviewers now receive the complete set of distinct built-in risk
findings for the current Gate attempt. Existing commands and configuration
continue to work unchanged.
