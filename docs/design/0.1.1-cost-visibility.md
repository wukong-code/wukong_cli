# 0.1.1 Cost Visibility

> 状态：实现完成，待发布。
> 目标版本：0.1.1。
> 最后更新：2026-08-18。
> 前置版本：[0.1.0 Trusted Local Loop](0.1.0-trusted-local-loop.md)（已发布）。
> 产品边界：补丁版本；继续 Free、local-first、BYOK，不新增命令、不改变 Loop/Gate 语义、不建设自有价格数据库、不做托管能力。

## 一句话定义

> **当发布内嵌的 provider catalog snapshot 携带所用模型的可靠 pricing 时，run 与 Loop 终态摘要显示离线估算的美元成本；没有可靠 pricing 时继续只显示 `Cost unavailable`。**

0.1.0 的成本合同规定"只有存在可靠 pricing source/version 时才显示金额"。
0.1.1 把这条合同落地：catalog 管道已经接入 models.dev，而 models.dev 自带
per-model pricing（USD / 1M tokens），发布管道已经把同一 snapshot 嵌入六平台
native 包。0.1.1 不再丢弃 pricing 字段，并用它把成本估算变成纯本地计算。

## 不变量

1. 成本估算不触发任何网络请求；唯一 pricing source 是 release-embedded
   catalog snapshot。开发构建没有内嵌 snapshot 时稳定显示 `Cost unavailable`。
2. 估算是显示层信息，不参与 Gate 判定、预算阻断或任何终态语义；
   deterministic 失败不能被任何成本信息覆盖。
3. 没有 pricing 的模型不打乱既有显示：完全无匹配时保持 `Cost unavailable`；
   部分模型有 pricing 时显示已匹配部分并加 `+` 后缀（如 `~$0.42+`）。
4. 不建设自有价格数据库，不做货币换算，不展示 provider 账单口径以外的金额。

## 功能列表

### P0：pricing 进入 catalog 与 snapshot

1. `CatalogModelEntry` 增加可选 `cost`（models.dev 字段名：input、output、
   cache_read、cache_write，USD / 1M tokens）；未知字段继续被忽略。
2. 发布 snapshot 生成脚本保留 `cost` 字段；metadata sidecar 增加
   `pricedModels` 计数（schemaVersion 保持 1，additive）。
3. release staging 验证新增硬门槛：`pricedModels > 0`，防止未来再次把
   pricing 意外剥掉（0.0.22 embedded snapshot 缺失的同类回归）。

### P0：per-model usage 统计

1. Goal 的 token 统计从单一标量扩展为按 model alias 的 input/output/cache
   拆分，复用现有 `TokenUsage` 与 `usage.record` 的 alias 口径。
2. `goal.update` durable record 携带 `usageByModel`；恢复路径兼容旧记录
   （无该字段时恢复为空，成本显示回退 `Cost unavailable`）。
3. `tokensUsed` 语义不变（仍是 grand total），预算阻断行为不变。

### P0：终态摘要显示

1. 统一估算与格式化入口：alias（`provider/model`）→ catalog pricing →
   USD 估算；≥ $0.01 显示两位小数，否则四位小数。
2. 覆盖四个既有摘要面：headless run summary（含 JSON report 的 `cost`
   字段）、headless Loop summary、TUI 普通回合摘要、TUI Loop 终态卡片。
3. reviewer token 仍不在 writer 聚合内，继续诚实显示
   `Reviewer tokens unavailable`；SIGINT 停止摘要没有 usage 数据，保持
   `Cost unavailable`。

## 明确不做

- 不做实时远端 pricing 查询或 pricing 网络回退。
- 不把成本纳入 token budget 阻断条件。
- 不做 reviewer/subagent 的独立成本聚合（需要新的 usage 管道，另行评审）。
- 不新增命令、配置项、telemetry event 或对外 evidence 格式。

## 验收

- 有 pricing 的模型在四个摘要面显示 `~$X.XX`；无 pricing / 无 snapshot /
  无 usage 时全部回退 `Cost unavailable`。
- 多模型 run 按 alias 分别累计；部分覆盖时显示 `~$X.XX+`。
- 旧 `goal.update` 记录（无 `usageByModel`）恢复后行为不变。
- snapshot strip 回归测试反转：`cost` 必须保留，其他未知字段仍被剥离；
  release staging 在 `pricedModels = 0` 时失败。
- 全量相关测试、typecheck、lint 通过；六平台发布管道沿用 0.1.0 门槛。
