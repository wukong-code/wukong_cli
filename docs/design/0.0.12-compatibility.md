# 0.0.12 Goal 与 Loop 兼容矩阵

> Internal engineering record — kept in Chinese. English product docs: the user guide and release notes.

> 目标：0.0.12 把产品统一为 `proof-pass` Loop，但不破坏 0.0.11 的本地会话记录和常用命令参数。

## 持久化 Goal records

| 旧数据 | 0.0.12 行为 | 兼容结论 |
|---|---|---|
| `goal.create.stopCondition=verify-pass` | 恢复时迁移为 `proof-pass` | 保留并升级 |
| `goal.create.stopCondition=scan-clean` | 恢复时迁移为 `proof-pass` | 保留并升级 |
| `goal.create.stopCondition=judge-pass` | 恢复时迁移为 `proof-pass` | 保留并升级 |
| `goal.create.stopCondition` 缺失 | 仍是普通 Goal，不自动变成 Loop | 保留 |
| 旧 record 缺少 `iteration` | 从 `0` 开始 | 保留 |
| 旧 record 缺少 `loopResult` | UI 使用旧 status/reason fallback；下一次 gate 后写入 v2 LoopResult | 保留 |
| 重启时 status 为 `active` | 恢复为 `paused`，由用户显式 resume | 保留安全语义 |
| `complete` 后存在 `goal.clear` | replay completion 后清空当前 Goal | 保留 |

迁移只发生在内存恢复层，不重写用户的历史 record 文件。新写入的 Goal 统一使用 `proof-pass`。

## CLI 与 TUI flags

| 0.0.11 输入 | 0.0.12 行为 | 计划移除时间 |
|---|---|---|
| `wukong loop ... --until verify-pass` | 接受，提示 deprecated，归一化为 `proof-pass` | 不早于 0.0.14 |
| `--until scan-clean` | 接受，提示 deprecated，归一化为 `proof-pass` | 不早于 0.0.14 |
| `--until judge-pass` | 接受，提示 deprecated，归一化为 `proof-pass` | 不早于 0.0.14 |
| `/loop --until <legacy>` | 接受并归一化为 `proof-pass` | 不早于 0.0.14 |
| `/goal --until <legacy>` | 接受并归一化为 `proof-pass` | 不早于 0.0.14 |
| `--max-iterations` | 保留；Guest/Free entitlement 会进一步收窄为 2/5 轮 | 保留 |
| `--every` | 保留；继续复用现有 scheduler | 保留 |
| `--dry-run` | 保留；不创建 Goal、不消耗 Loop quota | 保留 |
| `--model` | 保留；只影响 writer，0.0.12 reviewer 继承 writer model | 保留 |
| `--role` | 0.0.12 曾提供；2026-07-21 起移除，角色切换收敛到 TUI `/transform` | 移除 |

## 发布约束

- 0.0.12 不删除旧 enum wire value，确保旧 records 和旧 SDK payload 仍能解析。
- 归一化发生在 Goal 创建和恢复边界，gate 内部不再依赖旧条件。
- 移除旧 `--until` 值前，至少提前一个版本发布公告并统计实际使用。
